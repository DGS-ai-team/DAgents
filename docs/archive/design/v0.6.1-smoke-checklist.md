# v0.6.1 Smoke 验收检查清单（归档）

> 已归档；现行验收见 [`../../design/v0.9.1-smoke-checklist.md`](../../design/v0.9.1-smoke-checklist.md)。

**版本定位**：**产品化 Web UI 1.0** + `show_image` + Session Media API（Git tag **`v0.6.1`**）。

**前置**：建议先通过 [`v0.6.0-smoke-checklist.md`](./v0.6.0-smoke-checklist.md) 核心项。

---

## 环境与构建

| 项 | 要求 |
|----|------|
| 基线 | **`v0.6.0`** 或同分支开发构建；Node Web UI 已嵌入静态资源 |
| OS | Windows 10/11（主 persona）；浏览器亦可直连 Node 测 UI |
| LLM | 可用模型；测 thinking 时需 deepseek / qwen |
| 默认 URL | `http://127.0.0.1:<port>/ui/` 或 `/ui/chat` |

**快速命令**：

```bat
curl http://127.0.0.1:18765/health
cd node\webui\frontend && npm test && npm run build
go test ./node/internal/session/... ./node/internal/api/...
```

## 已知与 v0.6.1 设计差异

| 原设计 | 实际交付 |
|--------|----------|
| 三栏 + 可折叠诊断 | **两栏**；连接态在顶栏；运维详情在 **设置 › 通用** StatusPanel |
| 活动记录折叠块 | system 消息 **不进入**主消息流（无底部「活动记录」UI） |
| 设置 › 高级 › 始终展开工具 | 仍用 `/tools verbose`；设置页 toggle 可后续补 |
