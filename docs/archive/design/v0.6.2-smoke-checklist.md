## 环境与构建

| 项 | 要求 |
|----|------|
| OS | **Windows 10/11**（Shell 更新 / 剪贴板 / Toast 抑制） |
| 安装 | 含 `dagents-shell.exe`；Shell 登录自启或手动启动 |
| Manage | 可选：测更新 Toast / apply 时需可达 Manage 与 manifest |
| Desktop API | `http://127.0.0.1:18767`（Shell 在跑） |

**快速命令**：

```bat
curl http://127.0.0.1:18767/health
curl http://127.0.0.1:18767/v1/desktop/update
cd desktop\tray && go test ./...
cd node\webui\frontend && npm test
```
