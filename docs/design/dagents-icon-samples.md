# DAgents 图标样稿

`dagents-icon-samples.svg` 是一张独立 SVG 设计画板，展示 Node 与 Manage 可以共用的 DAgents 图标语言。它只用于视觉探索，不会直接改变业务 UI。

设计规则：

- 统一使用 24×24 逻辑网格，主要线宽为 1.6，采用圆角端点和连接。
- 品牌雪花采用六向、60° 的几何结构，并在中心使用晶体节点；完整雪花只保留给品牌锚点和成功状态，避免所有功能图标机械重复品牌符号。
- Auto 使用轨道和脉冲表达持续检查与唤醒；唤醒触发器使用时钟和回环箭头；Dreaming 使用月牙和低亮星点。
- 工作组使用三节点拓扑，经验/手册使用打开的文件，文件系统使用文件夹和切角晶体，终端使用命令提示符，浏览器使用球面经纬线。
- 深色画板中的卡片、边框和图标颜色沿用冷色产品语义；暖色只用于 Dreaming 与成功等状态提醒。

图标 key 与语义：`brand-snowflake`（品牌雪花）、`agent`（智能体）、`workgroup`（工作组）、`auto`（自主智能体）、`auto-overview`（自主总览）、`wake-trigger`（唤醒触发器）、`dreaming`（梦境整理）、`experience-handbook`（经验/手册）、`filesystem`（文件系统）、`terminal`（终端）、`browser`（浏览器）、`success`（成功）。
