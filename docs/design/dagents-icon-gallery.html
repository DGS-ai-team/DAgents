Auto 与总览图标候选Auto 复用普通 Bot + Sparkles；Auto 总览采用 ReceiptText；唤醒触发器继续使用 AlarmClock
推荐 · Bot + Sparkles与普通 Agent 同源，右上角小型 Sparkles 表示自主循环；16px 仍保留 Bot 轮廓与识别点。
旧候选 · Orbit + Bot + AlarmClock信息层级较多，轨道与行星感会削弱 Bot 同源性；AlarmClock 只在 wake-trigger 中表达唤醒。
推荐 · ReceiptText用任务记录与回执表达 Auto 总览，直接复用 Lucide；16px 保留纸张轮廓和文字线条，避免与工作组 Network 混淆。
旧候选 · LayoutDashboard + Sparkles仪表盘与自主标识层级较重；总览采用 ReceiptText 后，Network 可继续只承担工作组多节点语义。
