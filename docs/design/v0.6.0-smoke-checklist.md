# v0.6.0 Smoke 验收检查清单

**版本定位**：Windows 默认 Client = **Shell + Web UI** 首个完整闭环（Git tag **`v0.6.0`**）。  
**路线图**：[`v0.6-v0.7-roadmap.md`](./v0.6-v0.7-roadmap.md) §2.4 · **设计**：[`windows-desktop-shell.md`](./windows-desktop-shell.md) §4.1

> **API 注记**：清单里的 `/v1/sessions*` 已下线（410）；验收时改用 `/v1/agents` 与 `/v1/agents/{id}/hydrate|ack|context`。

---

## 环境与构建

| 项 | 要求 |
|----|------|
| OS | Windows 10/11 x64 |
| 安装来源 | Release Inno 安装包，或本地 `dist/dagents-local-assistant-windows-amd64-*` |
| LLM | `config.yaml` 已配置可用模型（或 Mock 仅测 UI/Shell 路径） |
| 默认端口 | Node `18765`（以 `config.yaml` `listen` 为准） |

**快速命令**：

```bat
dagents shell status
dagents doctor
curl http://127.0.0.1:18765/health
curl http://127.0.0.1:18765/v1/agents
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v "DAgents Shell"
```
