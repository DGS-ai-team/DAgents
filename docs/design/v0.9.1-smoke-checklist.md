# v0.9.1 预览版验收与收口清单

**版本定位**：正式版（1.0）前最后一个大预览（Git tag **`v0.9.1`**）。  
**主叙事**：Workgroup 协作可演示 + 开箱体验收口；边界写清楚，不把 1.0 范围提前塞进来。  
**相关**：[`workgroup-and-node-gateway.md`](./workgroup-and-node-gateway.md) · [`workgroup-d05-contracts.md`](./workgroup-d05-contracts.md) · [`CHANGELOG.md`](../../CHANGELOG.md)

**前置**：建议已通过 [`v0.8.x`](../../CHANGELOG.md) 安装/升级路径；本机可起 Manage + ≥1 个 Node（双 Node 场景需两台或两进程）。

---

## 0. 预览承诺面（写进发布说明）

### 0.1 本版承诺支持

| 能力 | 说明 |
|------|------|
| 工作组建组 / 订阅 / ACL | Manage + Node Dialer |
| Member provision | Home Node 工作区 + tool manifest |
| Supervisor 编排 | `assign_workgroup_task` 同步等待终态 |
| `@member` 直达 | 跳过编排、直接打成员 |
| 成员工作区工具 | **fs 全组** + 可选 **bash**（见 §0.2） |
| 信息型 HITL | `ask_workgroup_user` + UI 回答 |
| 取消当前 turn | Manage cancel → 唤醒等待 / `tool.cancel` |
| RunHistory 调试 | Console / Node「调试」侧栏 |
| 开箱首配 | Node 身份 + LLM；未完成前不启 Dialer |

### 0.2 明确不承诺（Known limitations）

| 项 | 说明 |
|----|------|
| 成员 browser / skills / triggers / wecom / child_agents | 无本地 Agent 会话，不在成员目录 |
| 工作区进程级沙箱 | bash 在成员目录 cwd 执行，**无额外隔离** |
| D05 全量 fixture 执行器 | INDEX harness + 部分 golden；非全量 op runner |
| Placement / 远端旁观 | 产品入口已拆除 |
| 企业级多租户 / Skill Library 完整生命周期 | 留给 1.0 |

### 0.3 默认工具策略（发版前确认）

| 项 | 建议 | 决议 |
|----|------|------|
| 新建成员默认勾选 | **仅 fs**（读/写/搜/图）；bash 默认不勾，UI 标明风险 | ✅ 已落地（`member_tools` default + Node `WorkspaceDefaultAllowToolNames`） |
| `GET …/meta/member-tools` | Console（Manage）+ Node WebUI（**本地嵌入**，不依赖 Manage） | ✅ |
