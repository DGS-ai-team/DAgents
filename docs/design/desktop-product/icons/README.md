# Desktop icon inventory

The canonical SVG files and their source/license inventory live under [`shared/icons/desktop/`](../../../../shared/icons/desktop/) and [`shared/icons/desktop/manifest.json`](../../../../shared/icons/desktop/manifest.json). This directory keeps the Desktop design entry points: the [gallery](./gallery.html) and [per-icon acceptance checklist](./acceptance-checklist.md) link to canonical assets without maintaining copies.

The product visual system retains its selected DAgents and Lucide geometry. The design manifest preserves the distinction between agent-entry and navigation semantics, Auto sparkles, and the original supplied geometry for workgroup and tools icons. See the [Web UI reuse audit](./reuse-audit.md) for reviewed source comparisons.
