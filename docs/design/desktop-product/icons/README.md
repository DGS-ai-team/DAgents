# Desktop icon source

This directory is the single source for icons used by the Desktop prototype. Most assets are local SVG files with a 24×24 viewBox, `currentColor`, a 2px stroke, and round caps and joins. `agent.svg`, `nav-agents.svg`, `auto.svg`, `nav-auto.svg`, `tools.svg`, `workgroup.svg`, `nav-workgroups.svg`, `attachment.svg`, `message.svg`, `file.svg`, `image.svg`, and `edit.svg` use user-provided filled geometry and `currentColor` so the existing CSS mask can scale them. `auto.svg` removes the supplied 1024×1024 robot art's separate base and pads its viewBox to center the head at a restrained size. `manifest.json` records the source and license mapping for each asset. Open the [offline icon gallery](./gallery.html) to inspect all 32 icons at 24px and 16px on white, sidebar and dark backgrounds. Use the [per-icon acceptance checklist](./acceptance-checklist.md) to record review decisions.

Icons from the product visual system retain their DAgents or Lucide geometry. `agent.svg` and `nav-agents.svg` share the two-person profile artwork from user-provided `Downloads/user.svg`; they appear respectively beside agent entries and as the agent navigation heading. `auto.svg` and `nav-auto.svg` use the same robot-head artwork from user-provided `Downloads/robot.svg`, with the former beside Auto entries and the latter marking the autonomous-agent group heading. The robot artwork has its separate base removed and its viewBox padded for a centered display. `tools.svg`, `workgroup.svg`, and `nav-workgroups.svg` use geometry from user-provided `Downloads/wrench.svg` and `Downloads/team.svg`, cleaned and adapted for Desktop's `currentColor` CSS mask; all remain DAgents project assets. `workgroup.svg` and `nav-workgroups.svg` share the same two-person artwork from `team.svg`: the former appears beside individual team entries, and the latter marks the workgroup navigation heading. Keep SVGs here; the prototype sync script copies this manifest into `prototype/public/assets/icons/` before dev and build.

The Desktop prototype now uses `send.svg` in both message composers. Its path geometry is extracted from Node Web UI's inline `UiIcon.vue` `send` symbol; the standalone SVG is a DAgents project asset. `play.svg` remains reserved for terminal command execution. Ordinary agent entries all use `agent.svg`; `tools.svg` is not used as an agent substitute. See the [Web UI reuse audit](./reuse-audit.md) for the standalone-asset hash comparison, UiIcon mapping, and reviewed download candidates.

## 复用决策

Node WebUI 的 `node/webui/frontend/src/components/UiIcon.vue` 将许多图形内联在组件中，没有单独的生产 SVG 目录。`docs/design/dagents-icons` 的 60 枚 SVG 已复制到 `docs/design/desktop-product/visual-system/dagents-icons` 作为 Desktop 视觉参考。原型已直接复用其中与当前语义相符且内容一致的 `terminal`、`browser`、`pending`、`success`、`error`、`create`、`more` 和 `upload`。`folder-open` 保留 Lucide 版本：现有“资源 · N”入口表示展开的资源集合，Lucide 的打开文件夹轮廓更符合该意图；不为复用同名 DAgents 资产而更换已在用图标。

本轮 `attachment`、`message`、`file` 各用于现有的添加附件按钮、返回完整对话按钮和通用文件资源。`upload` 保留上传语义，不冒充附件图标；原型当前没有真实上传操作。`image` 与 `edit` 加入画板和清单作为预留资产，原型没有对应控件时不新增按钮；顶栏仍使用文字菜单。未用 `earth` 替代浏览器窗口，也未用 `folder` 替代打开文件夹。
