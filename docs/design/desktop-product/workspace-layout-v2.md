## 工作状态与切换

```text
对话页 ──“资源 · N”菜单 / 消息中的“查看资源”──> 资源页(具体资源)
  ▲                                                │
  └──────── 顶部“返回对话” / 状态卡“查看对话” ────────┘
```

1. **对话页**：工作区导航行显示当前智能体名称、新建对话、`资源 · N`。资源按钮打开菜单，先列已打开资源，再列“新建终端 / 打开浏览器 / 打开文件”。选择具体资源进入资源页；资源由 Agent 新打开时，可以在消息的工具卡上出现“查看资源”，但不主动抢走当前输入焦点。
2. **资源页**：同一导航行左端固定 `返回对话`，后面是终端/浏览器/文件的资源页签和 `+`。对话不出现在这一组页签。关闭当前资源时优先选相邻资源；关闭最后一项回到对话。页签溢出时应有滚动或列表入口，不允许把窗口控件/状态卡挤出视口。
3. **资源页 Agent 状态**：右下角折叠态显示当前智能体、状态（空闲/生成中/待审批/已完成或失败）和必要数量，例如“待审批 1”。点击展开浮层，显示最近消息摘要、最近工具与当前审批；从浮层可查看完整对话，待审批可查看请求并作允许一次/拒绝。折叠态不放聊天输入，不重复资源标题。
4. **对话页审批**：有待审批时在消息流末尾或输入框上方显示完整审批卡，说明命令、执行 Node、影响范围和操作。资源页浮层中可快速处理，但须能回到同一完整审批。拒绝/过期/已处理的状态文案一致。
5. **会话归属**：不同智能体的消息、资源、状态、审批互不串线；切换智能体不应默默删除前一智能体已经打开的资源。切换 Node 时才依据真实连接边界取消旧流并重新获取状态；本原型只需模拟智能体隔离。

## 侧栏展开与收起

- 展开态按“智能体 / 工作组 / 自主智能体”三组保持原有层级。组标题不用下拉箭头；顶端提供一个明确的收起按钮，侧栏底部保留 Node 状态与设置。
- 收起态宽 60–64px，只显示收起/展开按钮、三组语义图标及底部 Node 状态/设置。**不要把所有 Agent 都缩成相同的 Bot 图标。**点击组图标显示贴近侧栏的浮层列表，列表中保留名称、当前选中状态和数量；选择后进入对象，浮层关闭，侧栏是否展开维持用户偏好。
- 所有只有图标的按钮要有 `aria-label`、`title` 或等效 tooltip；键盘可切换和选中。菜单或浮层打开后 `Escape` 可关闭，焦点返回入口。

## 图标资产规则

唯一语义源：[`visual-system/dagents-icons/`](visual-system/dagents-icons/)，其中包含 DAgents 语义 SVG 与已归集的 Lucide 来源。原型需要的图标可由构建脚本同步到 `prototype/public/assets/icons/`，但**不得手工维护另一套近似图形**。建议至少用以下语义 key：`agent`、`workgroup`、`auto`、`terminal`、`browser`、`file`、`settings`、`tools`、`pending`、`success`、`error`、`create`、`more`、`upload`、`refresh`、`collapse`、`expand`。确实缺少的通用操作图标先查既有 `lucide/` 来源，再补入同一资产目录并记录许可；品牌雪花继续使用现有 PNG。

## 本轮原型验收

- 对话与资源有明确双向入口；对话不在资源页签中；资源页不显示固定聊天输入。
- 资源页折叠状态卡只占右下角小区域；展开后能看最近消息、工具与审批；点击按钮能回对话；审批动作可操作且状态更新。
- 展开/收起侧栏、折叠态分组浮层及对象切换可操作；切换对象后前一对象的资源不被误删。
- 终端、浏览器、文件页签与新增/关闭资源仍可操作；图标从统一资产源同步，语义正确。
- 大屏与 800/1024/1280px 宽度下无横向页面溢出；状态卡、返回对话、资源切换及窗口菜单不会被遮挡。构建、已有测试及浏览器控制台检查通过。
