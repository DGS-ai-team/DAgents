日期：2026-10-18。当前状态：本轮核心能力及恢复入口修正版的原生窗口验收完成。未覆盖的原生操作范围列于下文，不代表这些能力尚未接入。

## 实现范围

- 文件页将导航与静默刷新分开，只检查当前可见目录和打开文件；默认目录 3 秒，文件内容 10 秒，大于 1 MiB 的文件内容 30 秒。工具完成、轮次结束、本地写入、返回页面与连接恢复可提前检查。
- 文件 GET 支持内容强 ETag 和 `If-None-Match` / 304；大小和修改时间只用作提示，不作为内容版本。
- 本地草稿保留原始保存 ETag。读取期间输入、保存期间重连、保存后旧读取晚到、旧 Agent 错误晚到均有保护；可下载当前编辑内容，不强制覆盖服务器文件。
- 文件缺失通过延迟确认进入同一刷新通道，避免热循环；隐藏、最小化、设置页暂停轮询，恢复后重查。稳定 Node 归属用于草稿，请求代次用于废弃旧响应。
- 浏览器只更新查看器画面，保留选择与最后成功画面；忙碌、断线、尚未启动按规则重试，所选页面关闭后重新选择有效页面。
- 终端继续使用原 WebSocket 输出；已有终端事件用于元信息同步，不因资源刷新重开会话或执行命令。
- 助手消息的完整 `html` / `svg` 围栏和独立完整块支持预览；HTML 使用无权限 sandbox iframe 与限制性 CSP，SVG 经 allowlist 清理后作为图片展示。HTML 中嵌入的静态 SVG 转为图片；源码复制、SVG 放大及紧凑卡片样式保留。
- 工作组助手正文也支持隔离预览；没有可靠 Agent 归属时不能激活资源链接。用户、系统消息及不完整流式块不激活预览。

详细规则见[自动刷新方案](../../resource-auto-refresh.md)、[资源引用与预览协议](../../../../development/resource-references.md)和[Node 接入说明](../../../../api/node-integration.md)。
