## 目标与边界

显式 HTML 展示块改为按实际内容收缩，避免短段落下方固定 280px / 190px 视窗留白。主消息区最高 600px、紧凑卡片最高 260px，最小 24px；长内容在内部滚动。SVG 继续按图片尺寸展示。协议不增加高度参数，源码切换及复制仍只涉及原始模型内容。

父窗口不能直接读取 opaque sandbox 内的 DOM，不能通过加入 `allow-same-origin` 或把模型 HTML 插入宿主来测量。候选采用固定测高 bootstrap，CSP 精确 hash 授权，sandbox 仅增加 `allow-scripts`；模型脚本、事件及外部资源仍被清理。尺寸消息须验证当前 frame window、随机通道、结构、有限数值和生命周期，父端再限制高度范围。文档和提示词区分“应用内置测量脚本”和“模型提供的脚本”。

- [x] 超长内容达到上限后内部滚动，外层消息布局不被无限撑大（自动边界回归及原生内部滚动复验）。
- [x] 紧凑卡片及源码返回预览正常恢复测量；宽度/图片监听已实现，数据图片初始布局通过。连续窗口缩放和延迟图片加载未单独做原生时序测试。
- [x] 高度允许缩小；使用独立 flow-root 内容容器的实际高度及 scrollHeight，不把 document 的 viewport 下限当内容高度；同高度不重复写入（代码审阅及自动回归）。
- [x] 模型脚本仍被移除，CSP hash 与固定脚本精确相符，无同源或 native 能力（自动回归及独立文档生成检查，原生复验待完成）。

- [x] HTML/SVG 展示协议、普通代码和原文回退、源码复制行为不变（完整前端回归）。
