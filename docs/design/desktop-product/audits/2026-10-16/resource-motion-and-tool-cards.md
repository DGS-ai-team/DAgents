# 资源切换时序与工具组卡片验收

日期：2026-10-16。范围：Desktop 消息页与资源页切换、Agent 设置/创建中的工具组卡片。

## 行为与设计

切换消息页与资源页时，页签立即响应，旧内容保留但暂不可操作；输入栏完成收缩、移动和展开后，目标内容才显示。使用动画完成事件及编号匹配，不使用固定延时猜测结束。快速反向导航、同一目标模式下继续切换页签、窗口尺寸变化都以当前动画为准；减少动态效果模式及设置页跳转保持即时响应。

打开中的文件/浏览器与终端展示组件保留，以避免切换时重建资源。文件与浏览器关闭后在离开完成时释放；工作组仅在实际展示时挂载，避免隐藏后继续轮询。此调整不改变 Node 终端的连接与结束语义。

工具卡片原先将图标和文字作为整体居中，短标题和长标题会使图标位置不同。现在使用固定 24px 图标槽、10px 间距及剩余宽度的文字区，文字在自身区域居中，长标题可换行。设置页和创建页共用该规则，保留原有黑灰配色、边框和选中状态。

| 工具语境 | 采用的现有图标 | 调整原因 |
| --- | --- | --- |
| 命令行 | `code-2` | 与交互式终端区分 |
| 子智能体 | `bot` | 与 MCP 的连接图形区分 |
| 记忆 | `brain` | 比书签更直接表达记忆能力 |
| 企业微信推送 | `send` | 与用户询问区分 |
| 终端 / MCP / 用户询问 | 保留 `terminal` / `network` / `message-circle` | 与各自行为相符 |

所有图形复用当前共享图标集，未添加新绘制的 SVG。

## 当前原生窗口的视觉证据

使用 Computer Use 观察真实 Tauri 窗口；候选为本地测试目录中的 `bin/dagents-shell-ui-polish.exe`，SHA-256 为 `219DD2A931B35D5FAA38B83B46390A336C5C9D6EB5E22E753AEE523BADCAA280`。Node 保持运行，本轮未发送模型消息、执行终端命令或保存 Agent 设置。

1. 原设置卡片：完成采集；图标随标题长短偏移，记忆使用书签、命令行与终端相似。
2. 消息 → 工作区：通过；约 320ms 时仍为旧消息页及移动中的圆形输入栏，工作区内容尚未显示；结束后出现文件列表和悬浮输入栏。
3. 工作区 → 消息：通过；动画中仍显示工作区，结束后恢复消息内容及完整输入栏。
4. 新设置卡片：通过；各列图标有固定位置，后方文字区居中，图标语义得到区分，原有选中状态保留。

原始证据保存在本地忽略目录 `.runtime-test-ui-polish-20261016/` 的 `01-tool-cards-before.png` 至 `06-tool-cards-after.png`。首次采集误含其他应用的截图已拒绝，未保存为证据。窗口缩窄尝试没有建立不同视口，未作为响应式通过依据。未通过截图宣称完整无障碍合规；真实键盘遍历与更多窗口尺寸仍需额外验收。
