# Desktop 资源工作区交互调整

日期：2026-10-16。具体编码由 Luna 完成，主线程审查集成、异步归属与验证结果。

## 交互约定

1. 顶栏“资源”菜单负责打开工作区、浏览器和新建终端，以及关闭当前资源。删除对话区上方的资源计数下拉及新增资源按钮，也删除“视图”菜单中重复的资源切换列表。
2. 已打开的对话、文件、浏览器与终端通过页签切换；已有终端重连和恢复会话不弹目标选择。
3. 新建终端先弹目标选择窗口。Windows Node 的本机选项为 PowerShell；其他平台使用 Node 默认终端，不能根据 Desktop 的运行平台猜测 Node 的 shell。远程 SSH 只列出当前 Agent 已启用、且全局也启用的 Linux 通道。SSH 由 Node 发起，凭据仍由 Node 持有。
4. “打开终端…”同时展示当前 Agent 的运行中会话和新建目标。打开弹窗时刷新 Node 当前会话列表；列表失败可单独重试，不会阻断现有会话恢复或新建目标。选择已有会话会复用同 Agent、同 session 的 Desktop 页签/relay，不重复创建 Node PTY；恢复时默认只读，用户明确启用手动输入后才向该终端发送按键。
5. 每个终端页签标明其所属 Agent，并说明模型也可能使用该会话。关闭页签或资源菜单中的“关闭当前资源”只 detach Desktop relay 并移除页签；“断开连接”detach relay 但保留页签，可再次连接。只有“结束终端”在应用内确认后，才通过 Node 删除会话；确认文字说明会中断命令，且 Agent/模型可能仍在使用。
6. Node 会在终端连续 10 分钟既没有输入也没有 PTY 输出后回收会话。打开会话列表、查看或读取旧输出不会刷新此空闲计时。Desktop 重启后仍可通过重新读取 Node 当前运行会话列表恢复；Node 自身重启后，内存会话注册表为空。
7. 终端输出使用资源面板剩余高度，删除旧有的 108px/390px 底部占位。悬浮对话卡覆盖在右下角，不挤压终端高度；容器变化合并到动画帧后重新 fit PTY 尺寸。
8. 单行主输入栏采用胶囊圆角，多行保持适度圆角，资源页输入也采用圆润样式。
9. 对话切到资源时，输入栏轮廓依次收缩成圆、移向右下、展开成悬浮输入栏，总时长约 840ms；返回执行反向过程。时长由共享常量统一管理。两个表单 slot 保持挂载，隐藏部分脱离 flex 布局并设置 inert/aria-hidden。快速切换、缩放和卸载取消旧动画；减少动态效果偏好直接切换。

## 悬浮消息栏迭代

- 默认仅显示约 56px 高的单行胶囊输入栏：状态图标、输入、展开/收起按钮与发送/停止按钮。状态通过图标、提示及无障碍文本表达，不额外占用一行名称与状态文字。
- 展开按钮在输入栏上方打开独立小消息面板，输入栏底部坐标不变。面板内容单独滚动，并保留最近消息、当前流式回复、最近工具及待审批操作。
- 消息面板右上角提供返回完整对话的按钮，移除原底部整行返回入口。收起时将面板内焦点移回展开按钮。
- 生成中按 Enter 不停止当前回合；只有明确点击停止按钮才停止。原有发送、草稿恢复、审批及按 Agent 隔离的业务逻辑仍由 DesktopApp 持有。
- 跨页面动画只测量紧凑输入栏，不再把展开消息面板算入目标尺寸。

## 实现边界

- Node HTTP/WebSocket 协议未改变。Desktop Tauri `desktop_terminal_open` 增加可选 `targetKind`、`targetId` 和 `shell` 参数，复用现有 `local` / `linux_channel` 目标。
- 新增 `desktop_linux_terminal_channels`，交集筛选启用通道与 Agent 绑定，只返回选择终端需要的元数据，不返回凭据引用或密钥。
- 取消、重试、切换 Agent 与卸载使旧弹窗请求失效。创建前再次校验弹窗所属 Agent 和当前选择，避免异步请求把目标开到其他 Agent。
- SSH 使用 Node 上通道/绑定已有的 shell 配置。恢复已有 session 不能附带新的目标或 shell。

## 终端生命周期追加

- “打开终端…”每次打开都会重新读取当前 Agent 的运行会话；会话列表和 SSH 配置分别加载、分别报错/重试。列表返回重复 terminal ID 时只显示一项，已打开同 Agent + session 的连接直接复用。
- 恢复列表通过已有 Node terminal summary 展示本机/SSH目标、工作目录和终端 ID 短尾；Rust client 透传已有字段，不扩展 Node API。
- 恢复已有 session 会清空旧输出快照后接收 Node 重放，避免重复历史；恢复后默认禁用终端 stdin，用户明确启用手动输入才向会话发送按键。屏幕提示明确 Agent/模型可能使用此会话，不声明独占或锁定。
- 页签 X 和“关闭当前资源”仅 detach relay 并移除 Desktop tab；“断开连接”detach relay 并保留 tab。“结束终端”要求应用内确认，Node HTTP 删除成功后才移除 tab，relay detach 仅作清理。确认说明终端命令会被中断。
- Node 终端保留 10 分钟无输入且无 PTY 输出时回收的既有策略；打开列表、恢复查看或读取旧输出不刷新该计时。终端页不修改该策略。
- 本轮针对性检查：Desktop UI 64 项通过；终端打开与结束确认组件挂载测试 8 项通过；终端 relay / Node 删除生命周期测试包含关闭视图不销毁、断开保留、显式结束先确认 Node 删除、失败保留页签与 detach 兼容，共 8 项通过。Agent/session 去重、连接复用与跨 Agent stale guard 已纳入 workbench 状态测试。
- Node 回归 `TestAgentTerminalToolSessionResumesAcrossWebSocketDisconnect` 验证工具创建的会话可被 UI 恢复，断连后工具仍能读写，再次恢复可重放输出，跨 Agent 接入被拒绝，显式 close 后移除；另对相关恢复、删除归属与空闲回收测试重复运行 3 次，均通过。
- 最新 Native 二进制已生成：`bin/dagents-shell-terminals-reviewed.exe`，18,848,768 字节，SHA256 `442C177DA8B34BB56B6EAFE759869B48E8A0B63688E5CB6B85ED9FAA0506B666`。修复了原生验收中发现的终端元数据漏传及启用输入按钮挤占输出高度的问题。
