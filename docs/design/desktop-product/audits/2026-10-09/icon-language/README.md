# 图标语言统一验收 · 2026-10-09

本轮由 Luna 实施，主代理在真实 `dagents-shell.exe` Tauri 窗口验收。规则入口为 [共享图标说明](../../../../../../shared/icons/README.md)，清单为 [生产 manifest](../../../../../../shared/icons/desktop/manifest.json)。

## 统一结果

- 普通操作采用跟随文字的黑灰色 `currentColor`；悬浮、选中、禁用通过深浅变化表达，状态图标可保留有含义的颜色。
- 保留已确认的人形智能体、工作组、Auto 四角星和文件轮廓。技能改用 Puzzle，浏览器使用简洁窗口，工作区使用打开的文件夹，附件使用回形针，发送使用向上箭头。
- 标准线性图标以 24-unit 画布、约 1.8–2px 描边、圆角端点为基准；提供的轮廓型路径保留，不强制转换成 stroke。按可见占用面积调整小尺寸显示。
- 设置导航一般使用 16px，接近铺满画布的 Puzzle 使用 14px。修正前截图见下方，修正后技能与相邻图标的视觉大小已协调。
- Desktop、Node、Manage 的相同语义引用同一共享资产。生产 manifest 有 33 个语义项，历史变体保留但不进入生产清单。SVG 使用根节点绘制属性，避免嵌入通用样式类。
