# Desktop 顶栏收束验收

日期：2026-10-09。编码由 Luna 完成，主代理使用 Computer Use 在真实 Tauri 窗口复验。

## 实现

顶级入口固定为 DAgents、资源、视图、智能体、帮助。移除重复的工具菜单与仅操作聊天输入的编辑菜单；设置进入通用页，帮助复用实际的版本/命令说明和反馈页。智能体操作显示当前对象名称，资源切换列表按当前智能体组织。

文字及悬停底色统一为中性灰；下拉项字号 13px、最小高度 36px。设置页隐藏侧栏按钮时保留占位并禁用按钮，菜单位置固定，保留过渡。窗口控制改用线条图形，最大化状态读取仅增加 allow-is-maximized 权限。

## 原生复验

- [x] 五组菜单显示、弹层间距及当前智能体名称。
- [x] 设置页与对话页顶栏位置一致。
- [x] 顶级 End、左右方向键切换菜单；下级方向键、End 跳过禁用项；Enter 执行；Escape 关闭并恢复焦点。
- [x] 通过菜单进入通用设置、版本/命令说明、反馈页。
- [x] 设置页打开工作区：路由切换到 /chat，实际页面保持工作区。
- [x] 资源页返回当前智能体对话；视图菜单切回已打开工作区。
- [x] 菜单关闭工作区：页签移除、计数归零、回到对话。
- [x] 切换普通/自主智能体后，菜单对象名称同步。
- [x] 原生最大化/还原与按钮名称同步；验收后恢复原窗口大小。

复验修复了工作区菜单关闭遗漏 opened 状态，以及设置跳转 /chat 时 watcher 覆盖目标资源页的竞态。后者由路由判定保留显式选中的资源页；显式返回对话仍设为 chat。

## 自动检查与范围

Luna 最终执行 Desktop UI 测试 26/26、Desktop build、capability JSON 校验与 diff 检查，均通过。构建仍有此前的 chunk 体积及动态导入提示。主代理另检查最终 diff。

本轮原生检查没有执行删除智能体、清空会话、停止真实任务、审批或提交反馈；这些菜单的可用状态通过模型测试覆盖。未通过 Windows UI 自动化执行终端命令，也未改变 Manage/浏览器配置。最终停留在普通智能体对话页。
