# 顶栏图标与页面切换验收

2026-10-09，Luna 实施，主代理通过真实 Tauri 窗口验收。

## 设计

顶栏最左位置保持固定 30×32px，不随设置模式消失，也不挤动菜单文字。图标保持 18px、中性黑灰色。

| 场景 | 图标 | 操作 |
| --- | --- | --- |
| 对话 | 圆角面板与左侧分隔线 | 展开或收起侧栏 |
| 设置 | 齿轮 | 页面标识，不进入键盘焦点 |
| 终端 | 终端 | 展开或收起侧栏 |
| 工作区 | 打开的文件夹 | 展开或收起侧栏 |
| 浏览器 | 窗口 | 展开或收起侧栏 |
| 工作组 | 工作组轮廓 | 展开或收起侧栏 |
| Auto 总览模态 | Auto 四角星 | 页面标识，关闭后恢复原页面 |

面板去掉原来的内部箭头和粗实心边；分隔线始终位于左侧，只在 x=6.5 与 x=9 间变化，表达窄、宽左栏。所有几何来自 `shared/icons/`。

[Morphicons 1.7.1](https://github.com/guillermolg00/morphicons) 的 Vue 绑定用于六个兼容描边资产的路径变形，组件始终挂载。填充工作组与含 transform 的 Auto 保留原 SVG mask，使用 110ms 交叉淡入淡出。动画尊重系统减少动态效果设置。顶栏禁止文字选取，避免连续点击控件选中菜单文字。

## 真实窗口验收

- [设置页](01-settings.jpg)：齿轮填补原空白位置；无障碍树显示“图形 设置”，不会作为侧栏按钮进入焦点。
- [返回后的收起状态](02-chat-collapsed.jpg)：收起侧栏后进入设置再返回，仍保持收起状态，名称为“对话 · 展开侧栏”。
- [展开状态](03-chat-expanded.jpg)：连续点击可以中断动画，最终状态正确；空格键可切换侧栏，名称与状态同步。
- [工作组](04-workgroups.jpg)：填充轮廓正常，菜单位置保持稳定。Manage 未启用，不改变此配置。
- [浏览器](05-browser.jpg)：页面图标切换为窗口，仍保留侧栏操作。浏览器能力未启用，此次只验证界面，不创建浏览器会话。

本轮观察到了面板与齿轮之间的中间变形帧。终端、工作区、Auto 模态的映射与资产兼容性通过代码和测试验证，未为截图创建终端或修改能力设置。验收结束关闭临时打开的浏览器资源，返回对话并展开侧栏。
