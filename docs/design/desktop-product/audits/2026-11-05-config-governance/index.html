验收记录

隔离设置 API 验收

在独立目录、端口 127.0.0.1:18801 上运行临时 Node，LLM profile 为 Mock；没有调用模型服务。功能总闸稀疏 PATCH、工具上限 0 拒绝/省略保留/reset、Manage 隐藏字段保留、无操作重启判定、NodeID 重启持久化均通过。profile multimodal PATCH 的 restart_required=false 表示无需重启 Node：新值会由 profile fingerprint 在下一次模型请求时应用；它不表示当前正在进行的请求即时切换。

raw-history 在 env=true/false 时，GET 返回环境生效值和 environment 来源；invalid env 文本也保持 environment 来源并按默认有效值 true 处理。三种情况下显式 PATCH 均返回 400 setting_controlled_by_environment，即使请求同时带其他字段，整包也不保存。

移除 env 并重启后，拒绝的 PATCH 不改变已保存值；settings 来源下普通修改仍生效。重启判定现在比较有效 raw-history 值，因此环境覆盖期间不会因隐藏保存值差异误报。
