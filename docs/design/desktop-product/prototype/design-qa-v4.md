# DAgents Desktop v4 原型验收记录

日期：2026-09-28。此次更新针对顶栏菜单、固定对话页签、资源状态坞和窄宽布局。所有操作均为浏览器中的交互模拟，不代表真实 Node、系统终端或外部浏览器已经连接。

| 检查项 | 实现与验证 |
| --- | --- |
| 顶栏菜单 | DAgents、文件、编辑、视图、运行、工具、帮助均使用单列分组菜单；显示快捷键或状态提示。负责人已在内置浏览器逐一打开七个菜单与新增资源菜单，确认菜单互斥、Escape 关闭和统一样式。通过。 |
| 文件与资源动作 | 新建对话、打开已有或模拟创建的终端/浏览器/README 示例、关闭当前资源；菜单动作保持当前 Agent 的资源上下文。资源切换入口只列已打开页签，新增资源按钮只负责创建/打开；没有真实系统文件选择或浏览器导航。负责人已逐一验收菜单入口。通过。 |
| 编辑菜单 | “全选当前输入”将焦点移回当前输入并选择文本；“清空当前输入”清空当前对话/资源输入或终端命令。撤销/重做以禁用态展示；未使用 Ctrl+Backspace 作为清空快捷键。 |
| 视图与固定页签 | 对话页签固定显示在资源页签左侧；资源页签可直接切换。视图菜单可切换侧栏、回到对话、切换已打开资源。 |
| 快捷键 | 已在原型中处理 Ctrl+N、Ctrl+O、Ctrl+Shift+B、Ctrl+Shift+T、Ctrl+B、资源页 Ctrl+W 和有草稿时 Ctrl+Enter，并阻止浏览器默认行为。Ctrl+W 在对话页不可用。Ctrl+A 仅显示为输入焦点内的常规编辑语义。 |
| 运行与工具 | 运行菜单可显示当前 Agent 演示状态、发送非空草稿、回到待审批卡、打开终端；不提供菜单内直接审批。工具和 DAgents 菜单说明 Node 状态为模拟，不执行连接。 |
| 资源状态坞 | 待审批卡固定在展开区上方，消息和工具记录独立滚动；折叠态输入仍可发送，资源页面保持当前视图。负责人确认 1024×768 下审批按钮可见。通过。 |
| Agent 与终端隔离 | 新建终端使用资源 id 独立保存输入/输出；唯一含构建日志的 `terminal-1` 仅属于预置 Agent，新建终端显示空提示符。新建对话同步清除当前 Agent 的审批/生成状态并取消尚未返回的模拟回复。负责人复验 Auto Dev 新终端无跨 Agent 日志、新建对话后资源坞为空闲。通过。 |
| 侧栏与空状态 | 移除通用助手的固定 `now` 标记；折叠图标不再显示微小计数，列表弹层仍显示分组数量。Auto 空对话用简洁提示说明可发送任务。 |
| 资源画布 | 终端、浏览器和文件示例使用轻微底色/边界层次区分；浏览器继续显示“演示内容”，文件继续标示只读示例。 |
| 自动检查 | `npm run build` 成功；`npm run test:sites` 通过（4/4）。 |

负责人另确认了侧栏折叠、Auto 空态、固定对话页签、菜单 Escape 关闭及资源坞关键路径。上述验收均针对交互原型；Node 状态、终端输出和浏览器内容仍为本地演示数据。
