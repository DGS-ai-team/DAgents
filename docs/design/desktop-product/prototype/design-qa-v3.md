# DAgents Desktop v3 原型验收

日期：2026-09-24。按 [工作区细化方案](../workspace-layout-v3.md) 在内置浏览器检查 `http://127.0.0.1:4174/`。这是模拟交互验收，不代表真实 Node、终端或浏览器已接入。

| 检查项 | 结果 |
| --- | --- |
| 对话消息 | 用户气泡与助手正文在同一阅读列左缘；助手无头像、无气泡，用户气泡为浅底。每条消息下方有低调时间。符合现有 Web UI 的主要结构。通过。 |
| 资源页快捷输入 | 从对话进入终端后，在右下悬浮坞输入并按 Enter 发送，输入清空且页面留在终端；展开可见刚发送的用户消息、模拟回复、最近工具与原待审批请求。通过。 |
| 审批可达性 | 展开坞可见命令、Node、影响范围和允许/拒绝；800×700 时内部滚动后按钮和“返回完整对话”可达。通过。 |
| 终端导航 | 资源页签直接标识 `终端 1 · bash`，没有第二个会话下拉或专用工具栏；页签右侧“终端选项”可打开清空/重新连接菜单。通过。 |
| 浏览器与文件 | 浏览器地址栏和文件标题各占单行；两页的低频资源选项在工具栏右端；右下悬浮坞保持一致。通过。 |
| 侧栏与顶栏 | 顶栏面板图标可折叠/展开侧栏。DAgents 菜单包含可点击的演示设置；侧栏底部只保留约 40px 的 Node 连接状态，没有重复设置齿轮。通过。 |
| 窄窗口 | 800×700 下文档滚动宽高为 800×700，资源页签截断但不挤出菜单，展开消息坞落在视口内并独立滚动。通过。 |
| 图标 | 原型实际出现的侧栏、资源、发送、审批和顶栏面板图标无空白；`shared/icons/desktop/manifest.json` 与其 canonical SVG 对齐，均为 24×24、`currentColor`、无写死十六进制颜色。画板文件已生成，但内置浏览器安全策略拒绝访问本地 `file://` 页面，**28 个图标的画板视觉检查未完成**。 |

原型构建成功，`test:sites` 4/4 通过。图标画板可由用户在本地打开 [`icons/gallery.html`](../icons/gallery.html) 查看 24px/16px 及白底、侧栏底、深底表现；本轮不能据此声称所有尺寸的图标都已视觉验收。真实终端末行遮挡、完整键盘导航、更多系统字体与跨平台窗口控制仍需在 Desktop 实装时验证。
