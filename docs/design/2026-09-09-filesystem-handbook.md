# 文件系统经验手册

日期：2026-09-09。状态：实现中，替代实验性 SQLite 手册设计。依据：用户要求指定目录，由模型自主创建层级、修改文件，不引入数据库。

## 产品行为

智能体设置提供手册根目录，留空使用 Agent 私有默认目录。目录配置由用户管理，模型在已配置的目录内组织文件，无须先提交数据库候选或等待单篇手册激活。文件是内容的唯一事实来源，用户使用外部编辑器修改后，后续文件读取应可见。

不强制固定目录结构。README.md 可作为入口，但不存在时允许从目录列表开始。界面提供目录路径、层级浏览、文件内容和修改记录；手册不再表现为一个大文本字段加数据库版本下拉框。

模型按需浏览、读取、创建目录和修改文件。已经发送给模型的请求内容保持不变；后续工具读取可以读到自己刚写入或用户更新的内容，不能用整轮冻结机制阻止这一行为。目录索引和读取内容有大小限制，不在每轮将整个目录塞入上下文。

## 存储与执行边界

- 根目录由可信 Agent 配置解析，工具只接受相对路径；默认目录按 Agent 分离，同工作目录不自动共享手册。
- 路径校验覆盖上级跳转、绝对路径、链接和 Windows junction；失败时不降级为任意文件访问。
- 修改前校验内容摘要，冲突提示重新读取；单文件写入采用临时文件与替换，失败不留下半篇正文。
- 历史与恢复信息使用文件保存；内部历史目录不作为普通手册内容暴露给模型。恢复产生新修改记录。
- 事实记忆继续复用现有 memory 存储。去除新代码中的手册数据库初始化与运行时依赖，不删除用户现有数据库或自动导出历史实验数据。
- 手册是经验资料，不能改变岗位职责上限、工具权限、预算或核心指令。文件操作仍经过既有执行策略和用量链路。

## 必须取得的验收证据

1. 真实 Agent 工具调用创建多级目录、写文件、读取、修改；磁盘内容与工具返回一致，不靠直接调用存储 helper 代替。
2. 同一会话写后读可见新内容；已构造请求不会被外部文件变化静默改写。
3. 两个默认配置 Agent 相互隔离；越界路径和链接逃逸失败，目录内正常层级可操作。
4. 外部编辑后新读取可见；旧摘要写入发生冲突，不能覆盖用户修改。
5. 服务重启后内容和文件历史可读，恢复旧内容保留之后发生过的修改记录。
6. 设置目录、文件树和内容通过真实 HTTP/UI 验收，切换 Agent 时旧请求不能覆盖新页面。
7. 每日维护和普通聊天都能在各自授权内使用手册；使用已配置 LLM 做真实创建与改写测试，记录磁盘证据及用量。

本文件记录验收要求，不代表上述能力已完成。整体阶段仍按 Auto 数字员工实施方案验收。
