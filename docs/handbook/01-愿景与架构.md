# 01 · 愿景与架构

本章是旧版手册兼容页；现行架构正文已统一到 [docs/architecture.md](../architecture.md)。

## 产品边界

DAgents 是本地优先的 Agent 控制台：Agent Node 负责模型、工具、文件、审批、会话和 Web UI；Manage 是可选的集中控制面，用于 Node 注册、工作组编排、审计和制品管理。它不是通用可视化工作流画布，也不会让 Manage 直接进入 Node 的执行环境。

## 三个关键边界

1. **Node 是执行边界**：工具和终端在 Node 上执行，policy/HITL 决定是否允许。
2. **Session 是隔离边界**：每个 Agent 会话有自己的历史、队列、runtime 和上下文；不同会话不共享可变消息数组。
3. **Manage 是协作边界**：跨机任务经 Workgroup；Node 主动通过 WS 连接 Manage，Manage 不主动访问 Node。
