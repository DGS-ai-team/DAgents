# 配置项参考

配置加载：`shared/config/config.go`。示例：`packaging/agent-client/config.example.yaml`。

**查找顺序**：CLI `-config` → `DAGENTS_CONFIG` → `packaging/agent-client/config.yaml`

---

## 顶层

| 键 | 类型 | 说明 |
|----|------|------|
| `agent_id` | string | 可选；缺省自动生成并写入 `.runtime/agent/` |
| `listen.host` | string | 默认 `127.0.0.1` |
| `listen.port` | int | 默认 `18765` |
| `local.endpoint` | string | Client 连接 URL（**仅 config.yaml**，Web UI 只读展示） |
| `fs_root` | string | 工作区根，默认 `./.runtime`（固定，不可配置） |

Web UI：**设置 › 通用**（runtime/agent）、**连接**、**上下文**、**安全**。

---

## llm

连接档案权威在 SQLite（`llm_configs.db`）/ Web UI「设置 › 连接 › LLM 配置」。Node YAML 中的 `llm` 仅作空库首次迁移种子（可选）。

| 键 | 说明 |
|----|------|
| `provider` | `openai` \| `deepseek` \| `qwen` \| `vllm`（迁移种子） |
| `base_url` | API 基址；留空用 provider 默认 |
| `model` | 模型名 |
| `api_key_env` | 环境变量名，默认 `OPENAI_API_KEY` |
| `mock` | `true` 时不调真实 API |
| `thinking` | `enabled` \| `disabled`（deepseek/qwen/openai） |
| `reasoning_effort` | thinking 强度 |

**`max_tool_loops`**：Agent 级配置（`agents.config_snapshot_json` → `defaults.llm.max_tool_loops`），新建 Agent / 模板决定；勿写在 Node `config.yaml`。

## manage

| 键 | 说明 |
|----|------|
| `enabled` | 是否连接 Manage |
| `url` | Manage 基址，如 `http://127.0.0.1:8020` |
| `node_token` | 可选鉴权 |
| `registration.base_url` | 上报给 Manage 的本 Node 可达地址 |
| `registration.interval_seconds` | 心跳间隔 |
| `registration.ttl_seconds` | Manage 侧 TTL |
| `registration.team` | Console 分组 |
| `a2a.enabled` | 是否拉 inbox |
| `a2a.inbox_wait_seconds` | long poll wait |
| `a2a.inbox_poll_seconds` | 断线短 poll |

---

## skills

| 键 | 说明 |
|----|------|
| `enabled` | 是否启用 skills |
| `max_in_prompt` | prompt 中 skill 数量上限 |

---

## compression

| 键 | 说明 |
|----|------|
| `silent_trigger_tokens` | silent 压缩阈值 |
| `blocking_trigger_tokens` | blocking 压缩阈值 |
| `idle_auto_compress_seconds` | 无动作自动压缩（0 = 关闭） |
| `idle_auto_compress_poll_seconds` | 空闲扫描间隔 |
| `idle_auto_compress_min_tokens` | 空闲压缩最低 tokens |

Web UI：**设置 › 上下文 › 压缩阈值**。

---

## tools

Node 级仅保留编码与 bash 压缩；工具组由各 Agent / 模板 `defaults.tools.enabled_groups` 配置。

| 键 | 说明 |
|----|------|
| `bash_output_encoding` | `bash_run` 输出解码 |
| `file_encoding` | FS 工具默认文件编码 |
| `bash_compress` | `bash_run` 输出清洗 |

---

## wecom

企业微信「消息推送」（群机器人 Webhook）。

| 键 | 说明 |
|----|------|
| `enabled` | 是否启用；默认 false |
| `webhook_url` | 完整 webhook 地址（含 `key=`） |
| `webhook_key` | 仅 key；与 `webhook_url` 二选一 |
| `api_base` | API 基址，默认 `https://qyapi.weixin.qq.com` |

---

## log

| 键 | 说明 |
|----|------|
| `level` | `debug` \| `info` \| `warn` \| `error` |

## 工作区子目录（相对 fs_root）

| 路径 | 用途 |
|------|------|
| `memory/sessions.db` | SQLite |
| `policy/` | 审批策略 |
| `skills/` | Skills |
| `history/` | 原始 journal（`history/YYYYMMDD/<session_id>.jsonl`） |
| `triggers/` | Triggers |
| `data/` | Agent 临时文件 |
| `prompt_context/` | soul / user / long_term |

- 示例：`packaging/agent-client/agent-card.example.json`
