## 版本规划

详细版本记录见根目录 [CHANGELOG.md](../../CHANGELOG.md)。

| 方向 | 说明 |
|------|------|
| Manage 策略集中化 | 自 Node 本地 policy 向 Manage 下发演进 |
| **Manage 能力市场** | Node 主动拉取 Skill/Plugin 列表并选择安装/移除；[manage-phase2-capabilities.md](../../design/manage-phase2-capabilities.md) §1 |
| **Manage 版本发布中枢** | Node 查询新版本、人工确认升级；同文档 §2 |
| **Manage 复杂 Workflow** | 多 Agent 执行计划与验收；同文档 §3 |
| **Manage 资源中转** | 跨 Agent 文件分享（Blob + artifact）；同文档 §4 |
| Web UI 增强 | Node `/ui/` 远程访问、鉴权、跨 Agent 统一入口（远期） |
| 观测 | Prometheus 覆盖 Node + Manage 统一指标 |
