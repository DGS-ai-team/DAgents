# 术语表

本表为 [DAgents 项目手册](../README.md) 附录。正文首次出现时会链到此处。

---

## A

**Agent Card**  
JSON 文件 `agent-card.json`，描述 Agent 能力、metadata（如 `role=compliance`）。Node 注册 Manage 时上报。

**Agent Node**  
Go 进程 `dagents-node`；LLM turn、工具、会话的本体。路径 `node/`。

**agent_id**  
Agent 全局身份字符串。**一进程一端口一 agent_id**。

**approval_required**  
SSE 事件；工具需人工审批（含子 Agent）。本地 turn 审批项在 **`hitl_required`** 的 `execute_tool` item 中。Client 弹 UI 后 `POST resume`。

**hitl_required**  
本地 turn 统一 HITL SSE；`items[]` 含 `user_information` 与/或 `execute_tool`。同批 ask + 审批共用一个 Node `PendingHITL`。

---

## C

**Client**  
终端人机界面。Python Textual（`dagents chat`）或 Go TUI（`dagents-client`）。**只连本机 Node**。

**consumeLoop**  
每个 `runtime` 的 goroutine；从 `MessageQueue` 出队并调用 `handle*`。

---

## D

**done**  
SSE 事件；语义 B——**轮到用户**（链结束或 HITL 暂停）。不等于 assistant 流式段落结束。见 [SSE事件速查](./SSE事件速查.md)。

---

---

## H

**HITL**  
Human-in-the-Loop；工具审批与 `ask_user_information`。

**Hub**  
`stream.Hub`；Manager 级 SSE 总线。`Subscribe(afterSeq)` 断点续传。

---

## M

**Manage**  
Python 控制面；Registry、工作组、Console。路径 `manage/`。

**MessageQueue**  
每 session 独占；`message` / `tool_result` / `resume` 等入队。

---

## O

**Orchestrator**  
`node/internal/turn.Orchestrator`；单步 LLM + 工具 + SSE。由 `runtime` 调用。

---

## P

**PendingHITL**  
runtime 上等待 resume 的状态；含 `Kind`（approval / user_information）。

**Policy**  
`.runtime/policy/*.approval.txt`；决定工具 auto / approval / deny。

---

## R

**RelayHub**  
子 Agent SSE 转发器；事件挂到父 `session_id`。

**runtime**  
单 session 运行时；拥有队列、Orchestrator、messages、pending。

---

## S

**Session**  
对话上下文；含 history、HITL、tool 循环计数。持久化于 SQLite（父 session）。

**SSE**  
Server-Sent Events；Client 收流式 assistant / tool / HITL / usage。

---

## T

**Turn**  
一次模型步（可含 tool batch）；多 turn 由队列串联至 `done` 或 HITL。

**TurnOptions**  
Manager 持有；FS 根、MaxToolLoops、压缩阈值、skills 等。

---

## 子 Agent 相关

**临时子 Agent**  
Node 内 `SpawnChild` 创建的子 runtime；不暴露端口、不持久化、工具白名单。

**RestrictedRegistry**  
子 session 工具执行器；仅允许白名单工具。
