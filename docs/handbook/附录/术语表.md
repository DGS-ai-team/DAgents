# 术语表

本表为 [DAgents 项目手册](../README.md) 附录。正文首次出现时会链到此处。

---

## A

**Agent Card**  
JSON 文件 `agent-card.json`，描述 Agent 能力、metadata（如 `role=compliance`）。Node 注册 Manage 时上报。

**Agent Node**  
Go 进程 `dagents-node`；多 Agent 实例、LLM turn、工具、SQLite；内嵌 Web UI `/ui/`。路径 `node/`。

**agent_id**  
本机 **Agent 实例** id（1 Agent = 1 主对话）。进程身份为 **`node_id`**（注册 Manage / ACL）。

**approval_required**  
SSE 事件；工具需人工审批（含子 Agent）。本地 turn 审批项在 **`hitl_required`** 的 `execute_tool` item 中。UI 后 `POST resume`。

**hitl_required**  
本地 turn 统一 HITL SSE；`items[]` 含 `user_information` 与/或 `execute_tool`。同批 ask + 审批共用一个 Node `PendingHITL`。

---

## C

**Client（历史）**  
曾指独立终端 TUI。现行人机入口为 **Web UI**；`dagents-client` 仅 probe/update/version。

**consumeLoop**  
每个 `runtime` 的 goroutine；从 `MessageQueue` 出队并调用 `handle*`。

---

## D

**done**  
SSE 事件；语义 B——**轮到用户**（链结束或 HITL 暂停）。不等于 assistant 流式段落结束。见 [SSE事件速查](./SSE事件速查.md)。

---

---

## H

**HITL**  
Human-in-the-Loop；工具审批与 `ask_user_information`。

**Hub**  
`stream.Hub`；Manager 级 SSE 总线。`Subscribe(afterSeq)` 断点续传。

---

## M

**Manage**  
Python 控制面；Registry、**Workgroup**、Console。路径 `manage/`。

**Member**  
工作组成员；在指定 **Home Node** 上 provision，工具仅在成员工作区内执行。不是侧栏本地 Agent。

**MessageQueue**  
每 Agent runtime 独占；`message` / `tool_result` / `resume` 等入队。

---

## N

**node_id**  
Node 进程全局身份；Manage 注册与工作组 ACL 使用。

---

## O

**Orchestrator**  
`node/internal/turn.Orchestrator`；单步 LLM + 工具 + SSE。由 `runtime` 调用。

---

## P

**PendingHITL**  
runtime 上等待 resume 的状态；含 `Kind`（approval / user_information）。

**Placement（已废弃）**  
原「远端放置 / 旁观」产品路径；已拆除。跨机请用 **Workgroup**。

**Policy**  
`.runtime/policy/*.approval.txt`；决定工具 auto / approval / deny。

---

## R

**RelayHub**  
子 Agent SSE 转发器；事件挂到父 Agent。

**runtime**  
单 Agent 运行时；拥有队列、Orchestrator、messages、pending。

---

## S

**Session（内部）**  
实现细节；用户可见单位为 **Agent**。对外勿再暴露多 session CRUD。

**SSE**  
Server-Sent Events；UI 收流式 assistant / tool / HITL / usage。

**sandbox（已移除）**  
原进程/Docker 沙箱；v0.8.x→0.9 删除。现行靠工具组 + `fs_root` + 成员工作区。

---

## T

**Turn**  
一次模型步（可含 tool batch）；多 turn 由队列串联至 `done` 或 HITL。

**TurnOptions**  
Manager 持有；FS 根、MaxToolLoops、压缩阈值、skills 等。

---

## W

**Web UI**  
Node 内嵌人机入口（`GET /ui/`）；创建 Agent、对话、设置、工作组。

**Workgroup**  
Manage 侧协作单元：Supervisor（Leader）编排或 `@member` 直达；契约见 `docs/design/workgroup-d05-contracts.md`。

---

## 子 Agent 相关

**临时子 Agent**  
Node 内 `SpawnChild` 创建的子 runtime；不暴露端口、不持久化、工具白名单。

**RestrictedRegistry**  
子 Agent 工具执行器；仅允许白名单工具。

---

## 已废弃术语

阅读 CHANGELOG 或旧 issue 时可能遇到；**现网文档不再使用**。

| 术语 | 现网对应 |
|------|----------|
| Brain / Body / Proxy | Go Agent Node |
| Python Agent API | Go Node HTTP/SSE |
| 独立 TUI 对话 Client | Web UI `/ui/` |
| Placement / Edge Tunnel | Workgroup |
| Agent 可选沙箱 | 工具组 + fs_root（无沙箱后端） |
| `/v1/sessions*` CRUD | `/v1/agents/{agent_id}/...` |
| Register Center | Manage Registry |
| `connection_id` 多 Backend SSE | 单 Node 本地 SSE |
