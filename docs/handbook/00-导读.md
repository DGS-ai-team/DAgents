# 00 · 导读

## 本章回答什么问题

读完本章，你应能：

- 知道本手册的组织方式与阅读顺序  
- 理解 DAgents 高频术语  
- 根据角色选择一条读者路径  
- 从手册章节定位到 `node/`、`client/`、`manage/` 源码目录  

---

## 1. 手册是什么

**DAgents 项目手册**（`docs/handbook/`）是仓库**唯一**技术文档正文入口。深度专题见 `docs/architecture/`、`docs/design/`；本手册负责导航与主干正文。

设计原则：

| 原则 | 说明 |
|------|------|
| **核心 → 外围** | 先 Agent Node 运行时，再 Client API，再 Manage/A2A，最后运维与案例 |
| **能读源码** | 每章给出「概念 → 文件」索引；细节以 `node/internal/*/REFERENCE.md` 为准 |
| **全中文目录** | 章节文件名与标题均为中文；代码符号、HTTP 路径保持英文 |
| **单源维护** | 架构变更先改手册对应章，再改模块 README；避免在多处重复同主题正文 |

当前发布版本见根 [CHANGELOG.md](../../CHANGELOG.md) 与手册 [README.md](./README.md) 首页。

## 2. 术语速览

完整定义见 [附录/术语表.md](./附录/术语表.md)。以下为开卷必备：

| 术语 | 含义 |
|------|------|
| **Agent Node** | Go 进程 `dagents-node`；LLM turn、工具、会话、SQLite；监听本机 HTTP/SSE |
| **Client** | 终端人机界面；**只连本机 Node**，不连 Manage |
| **Manage** | Python 控制面；注册、A2A 中继、Console；**不参与** Client 会话路径 |
| **`agent_id`** | Agent 身份；**一进程一端口一 `agent_id`** |
| **session** | 一次对话上下文；含 messages、pending HITL、tool 循环计数 |
| **turn** | 一次模型步（可能含 tool batch）；由队列驱动多步直到 `done` 或 HITL |
| **MessageQueue** | 每 session 独占；`message` / `tool_result` / `resume` 等入队 |
| **Orchestrator** | `node/internal/turn`；单步 LLM + 工具 + SSE |
| **Hub** | Manager 级 SSE 总线；`Subscribe(afterSeq)` 断点续传 |
| **HITL** | Human-in-the-Loop；工具审批、`ask_user_information` |
| **A2A Task** | 跨 Agent 协作单元；**经 Manage** 投递，禁止 Node 直连 peer |
| **ComplianceExecutor** | Node 侧 A2A inbox 执行器；`RunInboxTurn` 跑 callee turn |
| **子 Agent** | Node 内临时 session；共用进程与 FS 根，不单独暴露端口 |

## 5. 与模块 REFERENCE 的关系

| 层级 | 位置 | 写什么 |
|------|------|--------|
| **手册** | `docs/handbook/` | 为什么、怎么串、读源码路径 |
| **包 README** | `node/internal/*/README.md` | 包职责、文件一览、协作图 |
| **REFERENCE** | `node/internal/*/REFERENCE.md` | 类型、函数、字段、配置键 |

改 API 或行为时：**REFERENCE → 包 README → 手册对应章**，顺序保证细节不丢。
