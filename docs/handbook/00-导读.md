## 关键术语

| 术语 | 当前含义 |
|---|---|
| Agent Node | Go 进程，承载多个 Agent、工具、会话和内嵌 Web UI |
| Agent | Node 上可配置、可注册的长期对象，拥有自己的模型/工具/策略配置 |
| Session | 一个 Agent 的独立历史、队列、runtime 和上下文边界 |
| Turn | 从一次输入到终态或 HITL 暂停的连续执行单元，可能包含多个 Step |
| Step | 一次模型请求及其工具批处理边界 |
| Manage | Python 控制面，负责 Registry、Workgroup、Console 和制品服务 |
| Workgroup | Manage 编排多个 Node 上已有 Agent 的跨机协作单元 |
| HITL | Human-in-the-loop，审批或向用户提问后再继续 |
