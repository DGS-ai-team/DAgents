# 06 · 运维与案例

## 本章回答什么问题

读完本章，你应能：

- 启动本地开发栈（Node + Client ± Manage）  
- 理解 Release 包布局与安装方式  
- 选择目标 OS 的构建策略  
- 找到集成案例与安全/观测文档  

---

## 1. 本地开发栈

### 1.1 最小联调（仅 Node + Client）

见 [03 §6](./03-API与Client.md)。

### 1.2 含 Manage

```bash
python run_manage.py          # 默认 :8020
# 或 docker compose（见 packaging/manage/）

go run ./node/cmd/dagents-node -config packaging/agent-client/config.yaml
# config 中 manage.enabled: true
```

**脚本**：`run_dev_stack.py` — 可选一键起多组件。

### 1.3 CI 与测试

| 范围 | 命令 |
|------|------|
| Go Node | `go test ./node/...` |
| Go Client | `go test ./client/...` |
| Python | `pytest tests/ -q`（Manage 单测前须 `bash manage/console/build.sh`） |
| 前端静态资源 | Web UI / Manage Console **不入库**；CI 与 Release 构建前分别执行 `node/webui/build.sh`、`manage/console/build.sh` |
| Workflow | `.github/workflows/pr-tests.yml` |

## 2. 打包与安装

### 2.1 本地助手包

**路径**：`packaging/agent-client/`

| 资产 | 说明 |
|------|------|
| `config.example.yaml` | 配置模板 |
| `agent-card.example*.json` | Agent Card 示例 |
| Release tarball/zip | `dagents-local-assistant-*` |
| Windows 安装包 | Inno / Tauri Setup（见 `packaging/windows/`） |
| Linux `install.sh` | 见 `packaging/linux/install.sh`（打入发布包根目录；`scripts/linux/` 为 systemd/SysV） |

**组装脚本**：`scripts/package_local_assistant.sh`、`scripts/ci/assemble_local_assistant_bundle.sh`

### 2.2 Manage 包

**路径**：`packaging/manage/`、`manage/README.md`

Docker 镜像、`docker compose` 示例见 `packaging/manage/README.md`。

### 2.3 启停约定（Linux）

发布包根目录 `./dagents` / 安装后的 `dagents`：默认后台启动 Node 并打印 Web UI；`dagents node --foreground` 前台调试。原 Client `--withnode` / `chat` / `tui` 已移除。

## 3. OS 兼容与构建

| 主题 | 说明 | 文档/路径 |
|------|------|-----------|
| Go 静态构建 | glibc / musl 矩阵 | `node` 构建脚本、手册 §3 |
| 推荐第三方 CLI | OfficeCLI 等 | `packaging/runtime/RECOMMENDED_CLI_TOOLS.md` |

**原则**：目标机跑 **Go Node**（人机用 Web UI，可同机或隧道）；Manage 可另机（较新 Linux/容器）。

## 5. 安全与观测

| 主题 | 现网范围 | 参考 |
|------|----------|------|
| 分阶段安全验收 | policy、本地 bind、Manage token | 见本手册 §5 与 policy 实践 |
