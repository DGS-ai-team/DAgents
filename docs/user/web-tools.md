# 网页搜索与抓取

`web_search` 用于检索网页，`web_fetch` 用于读取指定网页的正文。这两个工具使用 DeepSeek Search / Fetch 协议，直接调用网页服务，不需要启动浏览器。

## 配置

在 Desktop 的「设置 → 共享服务」中配置网页服务：

1. 填写 Base URL。使用 DeepSeek 官方服务时填写 `https://api.deepseek.com`；也可以使用支持相同协议的代理地址。
2. 填写该服务的 API Key。网页服务配置独立于聊天模型配置，切换聊天模型不会替换网页服务的凭据。
3. 按需开启「网页搜索」或「网页抓取」，然后保存。两项可以分别开启。
4. 在智能体设置的工具能力中启用相应工具组。全局服务开关和智能体工具权限需要同时允许。

关闭的功能不会出现在可用工具列表或模型的工具定义中，也不能通过手写工具调用来执行。修改服务配置后，已有会话在下一轮使用更新后的配置。

Key 输入框留空会保留已保存的 Key；填写新值会替换；清除操作需要明确选择。如果仍开启任一网页功能，需要保留可用的 Key。设置读取不会返回 Key 明文；本机保存时使用已有的密钥加密机制。备份时应保留完整 `.runtime`，包括 `.llm_secret_key`。

## 使用

- 搜索：向智能体提出需要联网查证的问题，例如「搜索 Vue 最新版本的官方发布说明，并提供来源链接」。搜索支持 `site:`、`lang:`、`after:` 等语法。
- 抓取：提供网页地址，例如「读取 https://example.com/article 并整理要点」。抓取返回页面标题和 Markdown 正文，不提供登录、点击或浏览器交互能力。

工具调用沿用智能体现有的审批策略和工具次数上限。搜索结果和网页正文属于外部内容，不能授予工具权限，也不能替代用户指令。

## 常见问题

- 工具不在列表中：检查对应的共享服务开关，以及当前智能体是否启用了对应工具组。
- 认证失败：检查网页服务单独保存的 API Key 和 Base URL。
- 余额不足：检查网页服务账户余额。Search / Fetch 按服务提供商的规则单独计费。
- 搜索无结果：可以调整关键词；空结果本身不代表接口调用失败。
- 网页无法抓取：目标网站可能不可用、限制访问或没有可提取的正文。需要登录或交互时，可改用浏览器工具。

接口参数及服务限制见 [DeepSeek 网页搜索与抓取文档](https://api-docs.deepseek.com/zh-cn/guides/search/)。
