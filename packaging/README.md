# `packaging/`

分发辅助说明（非运行时模块），可随内网拷贝包附带给用户。

| 路径 | 说明 |
|------|------|
| **`OFFLINE_INSTALL.md`** | 离线安装步骤摘要；亦可复制到 README「离线依赖」章节 |
| **`prompt_context/`** | 系统提示侧车 **种子**（`soul.md` / `user.md` / `custom.md`）；运行时置于 **`<运行根>/.runtime/prompt_context/`**（首次可从种子拷贝，见 **`prompt_context/README.md`**） |
