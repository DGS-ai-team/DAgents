# `.runtime/scripts/` 索引

Agent 执行任务前可查阅本文件；新增或删除脚本时请同步更新。

| 名称 | 命令 | 说明 |
|------|------|------|
| （用户自行安装） | — | 将二进制放入本目录或系统 `PATH`；例如 **[OfficeCLI](../RECOMMENDED_CLI_TOOLS.md#officecli-安装摘要)**（`.docx` / `.xlsx` / `.pptx`） |

未加入 `PATH` 时使用相对路径，例如 `.runtime/scripts/<tool>`。
