# Legacy interactive prototype icons

These files were collected from `docs/design/desktop-interactive-prototype/public/assets/icons/` so the retired prototype can reference the repository-wide icon source without keeping its own copy. `aliases.json` maps every old filename under `legacy-prototype/<name>.svg` to its canonical shared SVG; exact duplicate geometry resolves to a canonical copy elsewhere in `shared/icons/`.

The prototype's public asset folder did not include per-icon source or license metadata. Where an asset matches a vendored Lucide SVG byte for byte, the corresponding Lucide source and ISC license are documented in `lucide/SOURCES.md`. Other historical assets remain attributed to the prototype collection rather than being assigned an unverified license.
